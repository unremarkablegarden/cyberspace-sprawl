# Roadmap

Rough order, not dates. Each milestone should leave the game playable.

| | Milestone | Scope |
| --- | --- | --- |
| ✓ | **M0 Foundations** | Chiba district, sign-in, walking, chat, character look, persistence |
| | **M1 Coffin** | Your capsule in the hotel: an interior room, place and turn furniture, kept forever. Visit other people's |
| | **M2 Scavenging** | Inventory. Junk to find around the city that comes back daily. New Yen |
| | **M3 Schematics** | Recipes found or traded; a workbench to craft furniture and gear |
| | **M4 Trade** | Barter between players (an escrow room so neither side can cheat), a fence who buys junk |
| | **M4b NPCs** | Fences and fixers with written dialogue who ask for vague things ("something that glows and looks like it's been through a war"). Rules-based first; later, possibly a small decision model that only ever *picks* from written options |
| | **M5 Jack in** | The matrix: a second plane reached from a deck, with data-fishing |
| | **M6 More Sprawl** | More districts along the BAMA, walking between them, a staff editor, seeded scattering of thousands of objects |
| | **M7 Asset pipeline** | Text → concept image → 3D model → decimate and palette-lock → R2, with a human choosing what goes in |
| | **Always** | Nightly backups of every room to R2, a staff moderation panel, mobile controls |

Ideas parked for later: the Boxmaker gallery (collages made from found
objects), a daily zaibatsu stock to trade, weather and time of day, guild
halls for cyberspace guilds.
